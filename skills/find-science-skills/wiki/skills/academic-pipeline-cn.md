# academic-pipeline-cn
## 一句话定位
[来源] 用于完整学术研究流程的协调器：研究 -> 撰写 -> 诚信检查 -> 审阅 -> 修订 -> 复审 -> 再修订 -> 最终诚信检查 -> 定稿。将深度研究、学术论文和学术论文审稿人协调为无缝的十阶段工作流程，包含强制的诚信验证、两阶段同行评审和可复现的质量门控。触发条件：学术流程、从研究到论文、完整论文工作流程、论文流程、端到端论文、从研究到发表、完整论文工作流程。
