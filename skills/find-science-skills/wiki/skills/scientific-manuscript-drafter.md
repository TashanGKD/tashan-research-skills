# scientific-manuscript-drafter
## 一句话定位
[来源] Draft or revise a peer-review-ready scientific manuscript from provided evidence, experiments, notes, code outputs, figures, tables, and verified references. Use when Codex must turn research artifacts into a paper while preserving claim-evidence traceability.
