# paper-finder
## 一句话定位
[来源] High-quality literature discovery assistant. Finds peer-reviewed papers from a user-curated list of journals and conferences for a given research topic, using OpenAlex source IDs (not fuzzy venue strings) plus LLM-driven query expansion and relevance re-ranking. Use this skill whenever the user want
