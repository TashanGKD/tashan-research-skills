# revman-calculator
## 一句话定位
[来源] RevMan data calculator for systematic reviews. Computes SD from SE/CI/IQR/range, calculates contrast data (OR/RR/RD/MD/SMD) from arm data, and combines study arms. Use when the user types `revman calc`.
