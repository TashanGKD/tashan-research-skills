# citation-reference-reviewer
## 一句话定位
[来源] Audit LaTeX/BibTeX references and IEEE-style citations for real-source existence, metadata correctness, DOI/URL validity, fabricated citations, missing keys, uncited entries, duplicate sources, and in-text/bibliography consistency. Use for citation verificatio
