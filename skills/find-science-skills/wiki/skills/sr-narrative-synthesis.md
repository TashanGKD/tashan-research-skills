# sr-narrative-synthesis
## 一句话定位
[来源] Non-meta-analytic synthesis methods per Cochrane Handbook Ch 12. Use when meta-analysis is not possible and alternative synthesis is needed. Three acceptable methods: summarizing effect estimates, combining P values (Fisher's), vote counting based on direction
